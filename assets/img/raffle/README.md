# Weekly Raffle banner

Drop the two assets for the **$100,000 Weekly Raffle** banner below the hero here.

| File | Purpose | Format | Recommended size |
|---|---|---|---|
| `character.png` | Mascot on the right of the banner | PNG (transparent) | ~520 × 360, subject anchored bottom |
| `coin.svg` | Tiny CTA-row icon next to the countdown | SVG (or PNG ~32px) | ~32 × 32 |

Missing files are removed silently — the banner falls back to its gradient background.
