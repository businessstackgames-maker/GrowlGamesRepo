# Community-chat avatars

Drop **12** small avatar images here; the live community chat picks them in round-robin.

- **Filenames:** `a1.png` through `a12.png` (PNG or JPG)
- **Size:** ~96 × 96, square. Will be displayed as a 32px circle.
- **Style:** monogram tiles, pixel-art portraits, or cropped photos all work.

If a file is missing, the chat falls back to a colored circle with the user's
first-letter monogram — nothing breaks.
