# Hero banner layers

Each promo slide is now built from **two images + live text**. The heading,
subheading, eyebrow badge, and CTAs live in the HTML (editable, crisp,
responsive) — you only upload the artwork.

Upload two files per slide:

| Slide | Background | Character |
|---|---|---|
| 1 (Jackpot) | `bg-1.jpg` | `char-1.png` |
| 2 (Winners) | `bg-2.jpg` | `char-2.png` |
| 3 (Deal you in) | `bg-3.jpg` | `char-3.png` |
| 4 (Luck) | `bg-4.jpg` | `char-4.png` |

- **Backgrounds:** full-bleed scene, landscape **~1520×545**, JPG/PNG/WebP.
  Keep the **left third darker / uncluttered** — the heading and CTA sit there.
- **Characters:** **transparent PNG**, tall (e.g. 900×900+), subject anchored
  to the bottom — it's pinned to the bottom-right of the slide.

Until a file is uploaded, the slide shows a branded gradient (and no
character), so nothing breaks. If you upload a different extension than above,
just tell me and I'll point the slide at it.
