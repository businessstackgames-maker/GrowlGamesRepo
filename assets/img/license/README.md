# Gaming licence seal

Drop your **Curaçao gaming licence** seal/badge here and it appears in the footer licence bar automatically.

- **Filename:** `curacao-seal.png` (this exact name is wired in `index.html`)
- **Format:** transparent PNG or SVG, roughly **120×120** (square). It renders ~54px tall.
- **Behaviour:** the seal is a link — point it at your regulator's public verification URL
  (edit the `href` on `.license__seal` / "Click to verify" in `index.html`).
- Until a file is present, a small lime **“CGB VALID”** placeholder badge shows instead.

> ⚠️ The licence text in the footer uses **bracketed placeholders**
> (`[Operator Name] N.V.`, `[OGL/2024/XXX/XXXX]`, etc.). Replace them with your
> **real** registered operator, company number, address, licence number and payment
> agent before going live. Only publish a licence you actually hold.
