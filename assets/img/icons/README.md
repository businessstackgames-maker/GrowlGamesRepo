# Sidebar & category icons

Optional replacements for the built-in navigation glyphs.

- **Format: SVG only**, single-color (use `currentColor`, or pure black/white) on a
  24×24 viewBox, transparent. This lets the app recolor them for hover/active states.
- Raster (PNG/JPG) will look worse and can't be recolored — please use SVG.
- **Filename:** by purpose:

| Nav item | Filename |
|---|---|
| Main / Home | `main` |
| Casino (group) | `casino` |
| Top Games | `top-games` |
| Slots | `slots` |
| Live Casino | `live` |
| Game Shows | `shows` |
| Hottest | `hot` |
| New Releases | `new` |
| Challenges | `challenges` |
| Help | `help` |
| Live support | `support` |
| Language | `language` |

Example: `slots.svg`

Anything you don't provide keeps its current built-in icon.
