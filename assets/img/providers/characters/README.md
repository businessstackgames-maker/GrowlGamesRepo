# Provider card — character art

One **character / mascot** cut-out per studio, layered above the background overlay on the
"Providers" cards (the studio logo sits on top). This is the "pops off the background" layer
shown in the reference.

- **Format:** **transparent PNG**, portrait, ~**440×560**. Subject anchored bottom-right.
- **Filename:** the provider **slug** below, e.g. `bgaming.png`
- Missing files simply don't render — the background + logo still show.
