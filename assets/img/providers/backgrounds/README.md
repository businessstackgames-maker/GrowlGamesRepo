# Provider card — background art

One **background scene** per studio for the "Providers" section cards. A gentle dark
overlay is applied automatically on top of this image, with the character art above the
overlay and the studio logo on top of everything.

- **Format:** JPG (or PNG), landscape-ish, ~**640×760** (cards are portrait, 5:6). Keep it dark/moody.
- **Filename:** the provider **slug** below, e.g. `bgaming.jpg`
- Missing files fall back to a per-studio gradient — nothing breaks.
