# Provider logos

One logo per game studio, shown on each game tile in place of the text name.

- **Format:** SVG preferred (or transparent PNG, ~240×80)
- **Color:** white / light monochrome (tiles are dark)
- **Filename:** studio name, lowercase and hyphenated

| Provider | Filename |
|---|---|
| Pragmatic | `pragmatic` |
| Evolution | `evolution` |
| Hacksaw | `hacksaw` |
| Relax Gaming | `relax-gaming` |
| Print Studios | `print-studios` |
| Big Time Gaming | `big-time-gaming` |
| Betsolutions | `betsolutions` |
| High 5 | `high-5` |
| Red Tiger | `red-tiger` |
| Spribe | `spribe` |

Example: `pragmatic.svg`

Any provider without a logo keeps its text label automatically.
