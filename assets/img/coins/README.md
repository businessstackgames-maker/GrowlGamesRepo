# Payment / crypto icons

One icon per currency.

- **Shape:** square
- **Format:** **SVG preferred** (or transparent PNG, 128×128)
- **Filename:** the lowercase ticker

| Currency | Filename |
|---|---|
| Bitcoin | `btc` |
| Ethereum | `eth` |
| Tether | `usdt` |
| USD Coin | `usdc` |
| Dogecoin | `doge` |
| Tron | `trx` |
| Bitcoin Cash | `bch` |
| Dai | `dai` |
| Ripple | `xrp` |
| BNB | `bnb` |

Example: `btc.svg`

Any currency without an icon keeps its built-in colored badge automatically.
