# Game thumbnails

Drop **one image per game** here.

- **Shape:** portrait **3:4** (e.g. 600×800 or 900×1200)
- **Format:** PNG, JPG, or WebP (WebP = smallest)
- **Filename:** the game name, lowercase and hyphenated

upload as few or as many as you like.
